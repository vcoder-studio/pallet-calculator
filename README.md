# Pallet Calculator

Free web calculator: how many boxes fit on a pallet — boxes per layer, layers (Ti × Hi), total boxes, load weight and height, with a top-view layout.

- **Web calculator:** https://vcoder-studio.github.io/pallet-calculator/
- **Chrome / Edge extension:** one-click version with PRO tools (mixed pattern, saved boxes, printable load sheet, CSV export, pallets per container). Store link will be added here after publication.
- **Privacy:** everything is calculated in your browser, nothing is uploaded. [Privacy policy](https://vcoder-studio.github.io/pallet-calculator/privacy.html)
